# OpenVLA诊断：先结束原问题，再加入事实行v1

2026-10-10，新增查询前冻结。[中性追加v1](OPENVLA_NATIVE_NEUTRAL_V1_20261010.md)中ramekin U成功而相同长度A失败，plate U也失败；本轮只检查问题与事实的包装位置，不预设因果机制或改进。

原追加格式是`In: What action should the robot take to Q\n事实?\nOut:`。新格式为`In: What action should the robot take to Q?\n事实\nOut:`。原版Q、事实句文字、大小写转换及Out标记保留；A/X/U只移动问号，使完整原问题先结束，再给出事实行。N逐字保持原生格式。

这是声明的文本包装变体，区别于未修改的官方追加入口。FP4／SDPA权重、图像和动作函数、相机、原生场景／init0、环境／策略seed=1、10步静置、300步上限、原生On／成功终止及正确碗独占评价相同，3厘米阈值不改。对象ID及事件只供评估，不输入策略。

先零查询验证旧N/A起始状态、像素、原N输入及事实真值一致；新A/X/U保持旧字符及token多重集和长度，task1为52、task8为50。若核查不符，新增rollout前停止并保留记录。两个实际模型图审阅后，重新跑两条N；两条均成功后依次跑两任务的A、U各一条，否则只记录正常基线失效，不继续附加条件。

最多6条新rollout／1800次查询、零额外策略诊断。全部条件预先固定，不按A结果选择是否观察U。旧N/A/U只作已见参考，不重计旧查询。本轮每块仅init0一条，不能替代三初始化的正常门槛；正式矩阵新增0、冲突行为0、主模型角色不自动更换。

本轮比较文本结构效应，不能将单初始化成功推广为稳定能力。A未过时仍不运行正式X/U；如格式有改善，后续正常核查须另冻结来源、初始化与预算。按用户5小时剩余额度小于10%的规则，完成已开始整轮后暂停新实验并总结提交推送。
