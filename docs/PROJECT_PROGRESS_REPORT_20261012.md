# VLA-LIBERO 项目进度与研究计划报告

日期：2026-10-12（Asia/Shanghai）。本报告依据截至当日已归档的实验结果、独立审计和查询账本编写；后续计划为优先建议，具体条件、预算与执行入口待另行冻结。

## 1. 核心进展与研究价值

项目在 LIBERO 闭环操作中研究固定权重视觉语言动作模型（VLA）的条件性脆弱性，并探索可见行为反馈能否提高有限查询预算下的黑盒攻击效率。当前最清晰的实证主线是：**在现有 OpenVLA Spatial 4-bit 配置、两个原生任务及固定背景事实模板内，撤除持续输入的背景语言能够恢复部分任务完成失败，并已在此前未用于项目开发的初始化上复现。**

固定第 60 次调用后撤除背景事实，在开发初始化中将正确独占完成从全程输入的 3/6 恢复到 5/6，在新初始化确认中从 3/6 恢复到 4/6。两批撤除条件均与原生指令的逐初始化成功／失败一致。恢复共涉及三个初始化，未出现相对全程背景事实的新退化；两批统计分别保留，不合并为总体有效率或显著性结论。

这一发现将研究问题推进到可直接检验的闭环行为层面：语言变化如何影响接触、搬运和放置，持续暴露与撤除如何改变完成结果，以及这些规律能否支持更有效的黑盒查询。下一阶段应围绕恢复效应的来源、时序边界和适用范围建立证据，再验证方法收益。

## 3. 支撑当前主线的实验结果

### 3.1 语言扰动敏感性与执行后果

OpenVLA Spatial task1（ramekin）与 task8（plate）分别使用自己的原生场景，在各任务的 init0..2 内配对比较。下表采用统一术语，数值均为正确碗独占完成：

| 条件 | 定义 | ramekin | plate |
| --- | --- | ---: | ---: |
| N | 原生指令 | 3/3 | 2/3 |
| P | 轻微等义改写 | 1/3 | 1/3 |
| U0 | 真实背景事实，全程输入 | 2/3 | 1/3 |
| A0 | 直接相关的正确辅助事实，全程输入 | 1/3 | 2/3 |

P、U0、A0 共新增 18 条完整轨迹、4036 次调用；六条 N 经来源核验复用。10 条失败中，7 条未记录双侧指垫接触，3 条已正确接触并抬升、但放置未满足原生中心距判据。所有新条件均未记录错误碗双侧接触或上盘子事件。

这些结果支持当前配置对语言变化具有敏感性，也建立了选物事件与最终执行结果分开评价的依据。双侧指垫接触是事件代理，不能直接等同于稳定抓握或语义理解。

来源：[语言扰动完整结果](OPENVLA_LANGUAGE_ROBUSTNESS_V1_RESULTS_20261011.md)。

### 3.2 固定时点撤除与新初始化确认

撤除条件记为 `U0_early60`：第 1..60 次调用与全程 U0 相同，第 61 次起恢复 N。60 次规则在确认前固定，独立于抓取、抬升或成功事件，确认中没有调整。

| 数据范围 | N | 全程 U0 | U0_early60 | 相对全程 U0 恢复／退化 |
| --- | ---: | ---: | ---: | --- |
| 开发：两任务各 init0..2 | 5/6 | 3/6 | **5/6** | 2／0 |
| 确认：两任务各 init3..5 | 4/6 | 3/6 | **4/6** | 1／0 |

开发轮恢复 ramekin init1 与 plate init0；确认轮恢复 plate init5。两批共 12 组的前 60 次实际输入、执行动作和 0..60 步记录状态完全相同，最大动作差为 0。确认轮全部 N／U0／撤除条件新跑，保留 ramekin init3、plate init4 的共同原生失败。

plate init5 提供了具体闭环后果：全程 U0 已建立正确接触并抬升，但终点中心距为 4.532 厘米，未满足原生小于 3 厘米的放置判据；撤除后第 105 步完成，中心距为 1.163 厘米。此案例支持正确目标上的执行恢复，不涉及错误目标转移。

当前确认范围是项目此前未开发的初始化；任务、背景模板和模型配置保持已见。撤除同时改变后续文本内容、长度和包装，效应来源需要匹配对照进一步区分。固定 60 次也不代表统一物理阶段，现有结果不支持内部注意力、记忆或图文主导机制推断。

来源：[开发轮结果](OPENVLA_TEMPORAL_WITHDRAW_V1_RESULTS_20261011.md)、[新初始化确认结果](OPENVLA_TEMPORAL_CONFIRMATION_V1_RESULTS_20261012.md)。

## 4. 阶段位置与研究主张

| 路线 | 当前状态 | 下一项关键证据 |
| --- | --- | --- |
| 正式事实冲突 | Phase 1 正常能力核查；正确辅助事实整体门槛尚未通过 | 可用且一致的 N/A 对照、事实真值与可执行目标 |
| 语言扰动与时序恢复 | 已完成开发诊断及一次新初始化确认 | 撤除效应来源、时序边界、新模板／任务适用范围 |
| CoVLA 等义协同 | 研究设计已建立，实验待开展 | 同状态完整四分支、等义与补丁合法性、弱单模态约束及独立确认 |
| 黑盒搜索方法 | 方法与评估路线已设计，搜索待开展 | 相同总查询预算下的搜索收益及最终独立评价 |

近期时序支线已获得初始化范围证据；总体路线没有据此完成整个 Phase 2 或 Phase 3。SmolVLA 双向 N 各 2/3、A 各 0/3；OpenVLA 最新 A0 为 ramekin 1/3、plate 2/3，整体正常门槛尚未通过。正式事实冲突矩阵与 80 条扩样仍待前置资格成立。

CoVLA 子问题独立比较原始、仅视觉变化、仅等义语言变化、联合变化四个分支。联合组失败更多，需要结合主效应与交互量 `Γ = p11 - p10 - p01 + p00` 才能解释，其中 p 为同一预定义失败事件的概率。当前协同现象及等预算攻击效率收益均为待验证目标。

## 5. 后续研究计划与完成判据

以下为依据当前证据提出的优先顺序。每批实验另行冻结条件、数据用途、查询上限和停止规则，计划数量不计入已完成结果。

| 优先级 | 研究问题与拟开展工作 | 完成判据 |
| --- | --- | --- |
| 1：拆分撤除效应 | 在固定切换点加入长度匹配的中性替换等对照，控制文本结构，区分内容变化与长度／包装变化 | 形成匹配初始状态的完整对照，明确哪些因素足以改变恢复结果 |
| 2：建立时序边界 | 在开发数据预先固定少量进入／撤除时点，记录接触、抬升、放置与完成；规则冻结后再独立确认 | 获得可复测的暴露与恢复边界，区分策略调用时点和物理阶段 |
| 3：扩展适用范围 | 固定规则，依次验证新背景模板、新任务；再加入通过自身正常能力核查的模型 | 每种扩展给出完整配对结果、原生失败及恢复／退化记录，确认样本不参与调参 |
| 4：验证方法收益 | 将成立的行为规律用于候选筛选与任务反馈校正，比较随机、单模态、独立组合及联合搜索 | 相同总查询预算下报告命中与任务后果曲线、反馈消融，并在最终留出数据评价冻结候选 |

事实冲突路线继续按既定协议建立正确辅助事实能力和目标身份锚，满足门槛后再进入 X 条件。CoVLA 子实验另行冻结等义文本、可见补丁与四分支预算。一般黑盒方法可以围绕稳定的条件依赖或时序风险展开；协同搜索的成立则需要对应的交互证据。

近期实验优先服务于三个论证任务：确认恢复是否可复测、区分最直接的替代解释、明确适用范围。更广模型覆盖和内部机制分析在这些证据形成后安排。
