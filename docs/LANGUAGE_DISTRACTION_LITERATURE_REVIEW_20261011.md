# 无关事实追加失败：论文核对与实验调整建议

核对日期：2026-10-11（Asia/Shanghai）。本次为文献与设计审查，新增策略查询为0，没有恢复暂停实验。本文件提出候选路线，不修改已冻结协议、历史门槛或结果。

随后用户采用本建议，已另冻结并完成[18条语言扰动诊断](OPENVLA_LANGUAGE_ROBUSTNESS_V1_RESULTS_20261011.md)，新增4036次策略调用。本文件保留审查时的建议与边界；实际结果、执行和成本以新报告为准。

## 1. 判断

**有直接可借鉴的论文。建议先将当前瓶颈作为语言扰动鲁棒性问题研究，再在具备一致条件能力的设置中测量事实冲突。** 不再把“找到一个总能成功的无关句”作为整个研究推进的唯一方式。

这不意味着放行当前事实冲突实验。正确事实条件 A 未通过时，X 的失败仍不能解释为图文冲突效果；U 失败可以作为鲁棒性结果报告，但不能作为有效中性对照已建立的证明。无关条件容易失败与模型忽视语言也可能分别出现在不同模型、任务和模板上，不能预设统一机制。

## 2. 当前证据与混杂

依据[接续汇总](EXPERIMENT_CONTINUATION_20261010.md)、[事实先行三初始化结果](PHASE1_OPENVLA_FACT_FIRST_NA_RESULTS_20261010.md)、[SmolVLA N/A](PHASE1_SMOLVLA_SPATIAL_NA_20261008.md)及[短中性句诊断](PHASE1_SMOLVLA_SPATIAL_SHORT_NEUTRAL_20261009.md)：

| 设置 | 已见结果 | 支持的判断 |
| --- | --- | --- |
| SmolVLA 同场景三初始化 | 两方向 N 各2/3，A 各0/3 | 正确事实载体尚不可用 |
| SmolVLA 中性追加、空格拼接、短句 | 每种设置均为init0两方向失败 | 缩短句子、改分隔符没有在这些已见样本解决问题 |
| OpenVLA 原生任务，事实包在动作问题内 | init0 U：ramekin成功、plate失败 | U的效果依任务而异 |
| OpenVLA 原生任务，事实前置 | init0 两条U均成功；三初始化 A各1/3，N分别3/3、2/3 | 位置改善仅局部复现；不能由两条U成功推断载体合格 |

现有U是 `Initially, the plate and the ramekin are both resting on the table surface.`。它对目标选择提供不了区分信息，但提及了目标承载物和任务参照物，属于“选择无关、任务实体相关”的控制，不能代表所有无关上下文。这是一项设计判断，不是已验证的失败原因。

现有A以第二参照物的 farther/closer 描述来解释 next to，增加比较、对象绑定和关系组合；A与U虽然等token长度，语义复杂度并不相同。`Initially`描述起始状态，若在所有策略调用中持续输入，需另区分初始真值与后续实时真值。它有时间限定，不因此自动算作后续错误事实，但策略能否利用该限定尚未验证。

失败包括未接触正确碗，以及接触、抬升后放置不合格。不能把全部超时等同于选错对象。当前使用OpenVLA原版Spatial FP4／SDPA，论文的OpenVLA-OFT或其他模型结果不能直接充作本配置基线；量化影响尚未隔离。

## 3. 最相关的原论文

### 3.1 Stable Language Guidance for Vision–Language–Action Models，ACL 2026

原文[论文与元数据](https://aclanthology.org/2026.acl-long.190/)、[PDF](https://aclanthology.org/2026.acl-long.190.pdf)，§3.2–3.3、§4.1–4.2、表2–3、附录F；PDF第3–7、18–23页。

R0是等义替换，R1为无关上下文，R2为常识对象描述，R3为推理结构，R4为否定式干扰，分别评估。表2中π0的R0／R1成功率为91.4%／55.8%；加入MCSI后R1为83.6%。π0.5的R1基线为93.2%，表明模型差异很大。这些是LIBERO-Goal上的论文结果，R0也不是未扰动原指令。

MCSI使用教师生成等义表达并训练策略，不是推理时多问几句或平均动作；RAS使用条件与空文本的动作分数差。可直接借鉴扰动分层，缓解算法则需要改变训练或推理接口。论文示例中一些“无关”内容带执行提示，其标签不能替代本项目对严格事实无关性的复核。

### 3.2 LIBERO-Plus，2025

原文[论文](https://arxiv.org/html/2510.13626v1)、[官方代码](https://github.com/sylvestf/LIBERO-plus)，§4、附录A.6、表4。

该工作把额外上下文、常识描述、推理改写分开，并用空指令及同场景目标替换检查语言是否被使用。可借鉴类别与诊断；其任务成功对改写不敏感，不能自动解释为语言理解强。原文的部分改写带时序内容，迁移时仍需核对目标、动作及约束是否保持。

### 3.3 When Vision Overrides Language / LIBERO-CF，2026

原文[论文](https://arxiv.org/html/2602.17659v1)、[项目](https://vla-cf.github.io/)，§IV–VI、表III。

同场景配置可行替代指令，并分别报告目标接触的grounding与完整任务success、指定目标与训练任务偏置。值得借鉴这种选物／执行分离。CAG具有空文本分支的免训练版本及另训VA版本；OpenVLA-OFT的平均指定任务success从0.4%升至0.9%（免训练），提升有限。移植到当前离散动作OpenVLA前需核查官方实现的混合层级，不能直接外推控制向量而称复现。缓解后应视作新的策略系统，另测N/A/U。

### 3.4 ICBench / IGAR，2026，v2

原文[论文](https://arxiv.org/html/2603.06001v2)，§3–5。

它在固定场景中修改指令属性／空间关系，主要构造不可满足的矛盾指令；评估30任务，每变体50条rollout。IGAR利用隐藏状态与注意力干预，免训练但不符合本项目严格黑盒访问。可借鉴最小语义修改；其矛盾条件“仍完成原任务”与本项目两侧可执行目标的跟随比例含义不同，LGS不能直接替代本项目指标。单纯停止或超时也不足以证明检测了矛盾。

### 3.5 Do Images Speak Louder than Words，EACL 2026，已有PDF

原文[作者PDF](https://www.cs.utexas.edu/users/ml/papers/zhang.eacl26.pdf)；本地文件位于papers，附录B.5与表9在本地PDF第14、17页。

作者以等长、不给任何选项提供优势的中性段落控制长度。第一轮中性条件准确率为QwenVL-2.5-7B 97.8%、GPT-4o 99.2%，没有要求达到100%。这一结果仅适用于其VQA设置，不能假定VLA也能承受额外文本。应借鉴匹配对照和原始退化报告，不能通过删掉失败中性样本制造干净对照。

### 3.6 Mixed Signals与Challenges in Understanding Modality Conflict，已有PDF

[Mixed Signals原文](https://aclanthology.org/2025.findings-emnlp.1351.pdf)，§2、§4.2；本地PDF第2–4页。冲突偏好分析基于一致输入答对样本，同时报告原始能力。可借鉴一致条件资格与覆盖率；不能按冲突结果挑选样本。

[Challenges原文](https://arxiv.org/abs/2509.02805)，§2–3、表1；本地PDF第2–3页。简单颜色／形状事实降低推理混杂，无颜色及其他形状描述主要是探针伪线索对照。可借鉴最小直接事实与实体提及控制；不能把探针结论搬成VLA行为因果证明。

## 4. 建议靠齐的设计

以下均是本项目候选设计，不是论文已证明的修复方法，也未代替当前冻结规则。

### 路线A：优先建立语言扰动鲁棒性结果

原生任务、图像处理、动作接口和完成判据固定。使用各任务内部配对状态；两个原生任务之间不称同画面目标切换。

| 条件 | 构造 | 目的 |
| --- | --- | --- |
| N | 原生指令 | 正常能力 |
| P | 轻量等义改写 | 对齐R0，区分一般改写与额外文本 |
| U0 | 不提目标、参照物、目的地的真实可见背景事实 | 区分一般文本追加；只采用已复核真值的事实 |
| U1 | 提及任务实体、但不能帮助目标选择的真实事实 | 沿用现有U的类别，检查实体提及效应 |
| A0 | 直接重复一个可见、相关关系，避免第二参照物比较 | 核查简单关系事实载体 |
| A1 | 现有比较／组合关系事实 | 检查新增语义复杂度 |

P与N比较等义变化；U0与U1按同一token预算及包装匹配；A0与A1另控制长度。不同家族不为硬凑等长而增加新语义。新模板的同长度对照要按实际token核查，不以字符数替代。需要长度曲线时另冻结短／长两档及对应控制。

每条记录：正确／错误对象接触，抬升，正确／错误目标完成，both／neither，原生SR和步骤。接触作为grounding代理，不能算成功抓握。基于既有完整轨迹重算这些描述性事件可先行完成，不产生策略查询；若事件缺字段则如实标缺失。

主表保留所有预先冻结有效样本，报告 `SR(N)-SR(U0)`、`SR(N)-SR(U1)`，以及grounding的相同配对差值。一般无关扰动造成的退化是这条路线的研究结果，U无需先成功才允许研究它。负差值也保留。已见init0..2及已调模板全部列为探索；新初始化和新模板在选定设计后冻结用于确认，不能边看确认结果边继续选句。

### 路线B：具备能力后再做严格事实冲突

优先选择短、直接、真实可辨认的单关系事实，使A/X只替换一个关系／属性，并让两侧都有唯一可执行目标。若无法实现，换任务或明确研究能力不足，不把原生显式任务成功当作关系推理通过。

N/A/X/U仍成套报告。保留全样本表，并提供按预先固定N/A/U能力条件定义的补充子集及覆盖率；低覆盖不能推广为模型整体模态偏好。`FR(X)-FR(U)`只是冲突条件相对匹配无关条件的额外退化，仍可能含词汇／关系复杂度差异，不能独自证明冲突机制。A/X的最小替换是更直接的内容对照，也需独立复现。

任务完成率与视觉／文本目标接触、完成比例分别报告，both／neither不删掉。neither频繁时说明目标偏好不可判定，不将它划给视觉或文本。现有N/A探索门槛不改写；新的能力条件、容许退化和规模必须在新协议中预先冻结。

## 5. 方法优先级与可行性

| 候选 | 现在可做的工作 | 限制与优先级 |
| --- | --- | --- |
| 直接事实、U0/U1分离、按失败阶段统计 | 文本与评估设计，不改受害策略 | 最高优先；改善是否成立待验证 |
| 事实前置、原动作问题紧邻输出 | 复用已有探索证据 | 已试且未稳定复现；不重复前置U或补其init1、2 |
| 等义文本候选开发集筛选 | 候选生成、零查询语义／token审查 | 所有搜索成本及失败保留；筛选后独立确认，不能叫MCSI复现 |
| CAG免训练分支 | 先核对官方实现与本接口 | 新的缓解系统；每步多分支成本另计，效果不保证 |
| MCSI训练、IGAR注意力、RAS分数引导 | 作为后续方法参考 | 超出当前固定权重／严格黑盒设置，当前不直接实施 |
| 换模型或精度 | 核查硬件与同任务原生接口 | 独立候选资格；不把旧结果混合、不预设量化导致失败 |
| 文本清洗器或外部规划器 | 可另定义系统级缓解 | 会改变被测系统；清掉X可能消除研究对象，不作为原策略冲突证据 |

## 6. 恢复后的小预算候选安排

本节仅供制定下一轮协议，当前不执行。保持此前“不重复或补测前置U”的决定。

1. 零策略查询：从现有轨迹汇总选物／执行失败，整理P、U0和A0候选；核查完整输入、真值、对象可见性、时间语义和token预算。候选上限及留出划分写入新协议。
2. 若恢复实验，首个候选块可只测两原生任务的P／U0／A0，各init0..2，合计18条新rollout；以当前300步上限计，最多5400次策略查询。N仅在完整来源核验后复用；无法复用则额外6条、最多1800次，预算先声明。所有18条都属于开发诊断，既有U1／A1仅作已见参考。
3. 若A0仍频繁失败，将该候选记录为事实载体能力不足，停止此载体的冲突解释；可继续按路线A报告鲁棒性。若选物稳定而完成差，则保留原生成功判据，并将执行阶段差异作为结果，不能事后放宽3厘米阈值。
4. 成功候选先冻结，再用留出初始化／模板确认；通过后才另立X/U预算。论文常用的50条／变体是确认规模参考，三个初始化仅足于探索，不照搬全量消耗。

建议采用路线A作为当前可产出的前置结果，路线B保留为条件性目标。这样既与VLA论文的语言扰动评价靠齐，也保留原项目事实冲突与后续黑盒搜索的边界。
