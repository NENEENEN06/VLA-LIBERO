# VLA 黑盒跨模态攻击研究计划

更新日期：2026 年 10 月 8 日。当前已确定的调整：**主实验模型由 SmolVLA 改为 VLA-Adapter 原版**。

研究目标：先参考 VLM 论文，在有效自然指代上比较一致图文、最小事实冲突及无关描述，探究 **文本与视觉怎样影响目标选择、何时由哪一侧主导**，再依据行为证据研究脆弱性与黑盒攻击。长期保留“刻画交互 → 发现脆弱性 → 验证范围 → 设计攻击”；当前优先第一阶段。攻击阶段仅用动作输出与任务成功失败反馈，诊断的仿真标注不向攻击端开放。

VLA-Adapter 原版承担当前能力核查、Phase 1 行为诊断及后续发现模型的角色，使用各套件对应的固定权重，`use_pro_version=False`。SmolVLA 的已完成试验保留为历史和比较资料；SmolVLA、PulseVLA-LIBERO 是后续验证候选，具体加入顺序和任务范围由各自能力核查后确定。详见[模型选择与基线准备](黑盒跨模态攻击/03_模型选择与基线准备.md)。

结果见 [Spatial 基线](../docs/SPATIAL_BASELINE_20261006.md)、[换模型与短版核查](../docs/PHASE1_MODEL_SWITCH_20261007.md)、[Spatial 选碗核查](../docs/PHASE1_SPATIAL_REFERENCE_20261008.md)。全部候选、失败和成本保留，试过的数据登记为已见探索数据。

1. 在 VLA-Adapter 上继续核查任务语义、输入和同场景目标绑定，提出并核对新的可执行候选；具体场景和英文模板确定后再冻结小规模试验。不自动重复已停止的候选，也不将未通过条件扩成大矩阵。
2. 按 [Phase 1](../docs/PHASE1_ENTRY.md) 先建立两个互补指代的 N 无辅助与 A 正确事实能力，通过后才加入 X 最小冲突与 U 等长无关描述。12→24→80 次是合格候选的条件性探索预算，候选前置诊断另计；报告跟随、偏好与不可判定。
3. 在独立初始化、模板及场景复现，再据证据决定固定授权目标的四组交互、时序及黑盒搜索。六任务 360 次先导和大规模确认均是后续条件性安排；验证候选须通过自身能力核查，不能沿用主模型的结论。

主模型与候选配置涉及两类主要架构路线，后续结论以实际通过核查并完成验证的模型为限。不同仿真版本、动作执行长度和训练配置的影响在评估中单列；总失败率包含自然失败，不能替代条件攻击成功率。模型来源见[模型文档](黑盒跨模态攻击/03_模型选择与基线准备.md)，正式协议维护在对应主题文档中。
