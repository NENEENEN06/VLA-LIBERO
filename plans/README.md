## 3. 四阶段位置与依赖

| 阶段 | 主要工作 | 进入下一步的证据 |
| --- | --- | --- |
| Phase 1 行为刻画 | 正常指代／正确事实核查，N/A/X/U 双向冲突 | 输入与真值有效，对照可用，独立复现 |
| Phase 2 脆弱性 | 固定目标四分支、CoVLA 等义协同、时序恢复 | 可重复交互、条件依赖或恢复边界 |
| Phase 3 范围验证 | 冻结现象构造，留出初始化／模板／任务／合格模型 | 适用范围、覆盖率及失效边界清楚 |
| Phase 4 方法设计 | 行为反馈搜索、等预算消融及最终留出评价 | 查询效率、任务后果与迁移证据 |

CoVLA 子实验不要求任务具有双向目标切换能力，但须有原任务正常基线、改写语义复核和单独语言效应。按当前路线完成有效 Phase 1 诊断后再冻结它的具体任务与预算，分别记录 E00/E10/E01/E11；不合并进事实冲突的 N/A/X/U。
