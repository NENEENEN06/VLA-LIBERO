## 接下来按这个顺序推进

1. 本轮三初始化、事实真值、实际token和画面检查已完成；先重新设计辅助事实载体，新稿在策略调用前冻结。
2. 原12条N/A已完成，N两个方向2/3、A两个方向0/3。新A仍须在固定三初始化核查，四块各至少2/3才继续；已有N仅在完全同配置时复用，新尝试另计。
3. 通过后新增12条 X/U，矩阵累计24条；允许 neither、both 或无稳定倾向，不按冲突结果筛样本。
4. 按门槛通过情况扩至 init0..9，新增56条，累计80条；再做独立模板／初始化复现和匹配状态动作诊断。
