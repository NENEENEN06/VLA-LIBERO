# VLA 黑盒跨模态攻击研究计划

更新日期：2026 年 10 月 7 日（先探究文本与视觉主导关系）。

研究目标：先参考 VLM 论文，在有效自然指代上比较一致图文、最小事实冲突及无关描述，探究 **文本与视觉怎样影响目标选择、何时由哪一侧主导**，再依据行为证据研究脆弱性与黑盒攻击。长期保留“刻画交互 → 发现脆弱性 → 验证范围 → 设计攻击”；当前优先第一阶段。攻击阶段仅用动作输出与任务成功失败反馈，诊断的仿真标注不向攻击端开放。

模型默认顺序为 **SmolVLA → VLA-Adapter → PulseVLA-LIBERO**。先用 SmolVLA 的 LIBERO 专用权重开发方法，再验证不同结构的 VLA-Adapter，最后扩展同类架构的 PulseVLA。首模型先做干净能力、语言有效性和调用成本筛选；若 SmolVLA 在适配正确后仍不满足条件，改用 VLA-Adapter。详细依据与切换条件放在模型文档中。

## 当前优先事项

2026-10-08 更新：用户确认的 VLA-Adapter Spatial 同 task 8 选碗核查也未通过。init0 中原生盘子旁碗1成功、ramekin 旁碗2失败，未扩样；两条件共 76 次 rollout 查询和 2 次诊断，见 [Spatial 报告](../docs/PHASE1_SPATIAL_REFERENCE_20261008.md)。当前仍须定位同场景目标绑定边界，不能进入事实冲突矩阵。

1. SmolVLA 为历史起步模型，共享 Goal 合法目的地各 10/10，但远近指代和事实追加失败。用户随后授权换模型，VLA-Adapter 的 init0 六次复查已完成：两条原生命令与两条事实追加成功，远近指代仍失败。用户追加的两条短版指令也均 neither；需要另选可验证的自然指代，不进入事实冲突。见 [换模型复查](../docs/PHASE1_MODEL_SWITCH_20261007.md)；Object 身份切换 0/3 仍为 SmolVLA 边界。
2. 按 [新 Phase 1 方案](../docs/PHASE1_ENTRY.md) 先验证自然属性／关系指代，再做无辅助、正确事实、最小冲突、等长无关四条件 × 两个互补指代。首批 12 次，通过后扩至 24、80 次；报告文本／视觉跟随、默认偏好和不可判定。轮廓标记与对称八条件改为后续扩展。
3. 在独立初始化、模板及其他场景验证条件性主导关系，然后扩第二模型。根据结果决定固定授权目标的四组交互与黑盒搜索；原六任务 360 次先导和大规模攻击确认均为后续条件性安排。

三模型验证覆盖两类主要架构路线。不同仿真版本、动作执行长度和训练配置的影响在评估中单列；总失败率包含自然失败，不能直接替代条件攻击成功率。模型来源集中列在[模型文档](黑盒跨模态攻击/03_模型选择与基线准备.md)，正式协议集中维护在对应主题文档中。
