## 指标和统计协议

### 指标应与实验类别对应

| 指标 | 定义或记录方式 | 适用范围 |
| --- | --- | --- |
| 干净与干预任务成功率 SR | 在可执行任务上，用对应的目标谓词判定完成 | 每个条件及每个任务均报告，不能省略干净基线 |
| 总失败率 FR | `1 - SR` | 描述总表现，包含自然失败，不直接作为条件攻击成功率 |
| 条件攻击成功率 cASR | 配对试验中，干净成功且干预失败的数量，除以干净成功数量 | 固定目标攻击；分母为零时记为不可估计 |
| 目标诱导成功率 | 原任务干净成功的配对样本中，发生指定错误目标操作的比例 | 必须预先声明目标操作和独立事件判据 |
| 风险事件率 U | 错误对象抓取、保护对象位移或进入指定禁区等事件的发生比例 | 事件逐类报告；任务所需接触不计为违规碰撞 |
| 恢复率和恢复时延 | 短时干扰撤除后，重新执行正确目标并完成剩余任务的比例与时间 | 区分接触前恢复、接触后恢复及失败删失 |
| 局部动作偏移 | 同一状态下，平移、旋转和夹爪输出的变化 | 分量先按固定尺度归一化；不能直接混加米、弧度和夹爪值 |
| 组合交互 Γ | 四组中同一风险或失败概率的差中差 | 仅在共享真值和配对条件中计算 |
| 冲突诊断指标 | 探针泛化、显式诊断准确性，以及不可执行指令下的具体行为 | 诊断输出与动作行为分别报告 |
| 文本／视觉跟随率 F_T / F_V | 冲突条件中，仅完成相应线索所指目的地的 rollout 比例；分母为全部有效冲突 rollout | 当前 Phase 1，双向冲突分别报告再等权汇总；不删去无法选择样本 |
| 条件主导差 D | F_T - F_V，同时报告两个都触发、两个都未完成的比例 | 正负只表述当前任务、载体和可靠性下的选择倾向，不表示内部注意力权重 |
| 线索可用性与选择变化 | 单侧及一致条件的预期目的地完成率；配对切换文本／视觉线索时的 A/B 选择变化 | 主导解释的前提；固定目标偏好及无效视觉载体独立列出 |

Phase 1 的预定协议为四条件 N/A/X/U × 两个互补 Q，主模型已确定 VLA-Adapter，当前仍在前置能力核查，尚未进入冲突矩阵，见 [入口](../../docs/PHASE1_ENTRY.md)。合格候选的每个 Q 内固定图像和基础指令；一致对照按有效自然指代评价，冲突表述双方跟随，不直接称攻击成功。因此不用 FR、cASR 或 Γ 代替主导指标；D 与 Mixed Signals 的 B 相反，B = -D。双向及全部四类结果分别报告，早期单场景仅给计数、比例。确认以初始化／任务为配对单位，区间与覆盖同时报告；同轨迹状态和动作不是独立样本。

“未行动”以末端运动、夹爪和物体变化共同标注，阈值根据仿真尺度及正常等待行为校准。没有原生拒绝接口的 VLA 不自动拥有拒绝能力；外部停止器的结果属于完整系统。不能以全零动作直接作为安全停止，尤其需要保留合理夹爪状态。

置信度只在模型确实提供相应接口时计算。离散动作 token 概率、连续动作不确定性和探针概率分别命名，不能互相替代。无概率输出时，使用重复采样稳定性等行为量，并明确额外调用成本。

### 同时保留全样本和条件样本

主表报告全任务集合中的干净 SR、干预 SR、失败增量及 Γ；补充表报告 cASR、错误目标率和恢复。干净成功子集由独立干净运行确定，不根据干预结果选择。

上述主表安排适用于后续固定目标攻击。当前另列四条件 × 双向表、指代可用性、F_T/F_V/D 与不可判定比例；全样本为主，N/A 均成功的配对子集为补充并报告覆盖率，子集只由非冲突对照决定。可选对称线索八条件另表，不与首轮或攻击结果混表。

跨模型首先使用相同任务与初始化集合，分别报告每个模型的全样本结果及本模型干净成功子集。共同干净成功子集只作补充比较，注明覆盖率和选择偏差，不能把偏容易的共同子集当作全部任务。

报告每个条件的任务数、初始化数、干净成功数量和运行错误数量。仿真或接口异常单独记为无效运行，并在相同配置下重试；模型造成的任务超时属于行为结果，不能作为系统异常删去。

### 配对统计和确认实验

- 以完整 rollout 为观测单位，保留四组配对；相邻动作或视频帧不算独立试验。
- 采用按任务再按初始化状态分层的配对 bootstrap，计算失败增量、Γ 和方法差异的 95% 区间。跨任务结论需要足够任务，增加同一任务的重复次数不能替代任务覆盖。
- 探索阶段对较多条件控制假发现率；确认阶段预先指定主要指标与比较。交互也可用混合效应模型做稳健性检查，但 logistic 回归中的乘积系数与概率尺度 Γ 不等价。
- 用先导数据估计方差和任务间异质性，再确定检测最小关注效应所需的样本量。每任务 50 次是起始评估配置，不保证某一效应已有足够统计功效。
- 预定义停止和扩样规则，不能因为区间尚未显著而反复补样本，直到得到正结果。

## Phase 3 的模型与环境范围

主实验与发现模型已确定为 VLA-Adapter 原版。SmolVLA 的前期试验保留，SmolVLA、PulseVLA-LIBERO 为后续验证候选；加入顺序、任务覆盖和共同可用集合待各自能力核查后冻结，不预先承诺三模型均能进入主导或攻击实验。版本与核查规则见[模型选择与基线准备](03_模型选择与基线准备.md)。VLA-Fool 中的 OpenVLA 用于理解文献与可实现的黑盒基线。

第一层覆盖 LIBERO Spatial、Object、Goal，第二层加入长任务 `libero_10`。模型基线首先遵循各自官方评估入口的初始化、稳定等待、图像处理和套件步数上限；所有修改都记录，不把全部套件统一裁成 200 步。[LIBERO 官方代码](https://github.com/Lifelong-Robot-Learning/LIBERO)、[LeRobot LIBERO 文档](https://huggingface.co/docs/lerobot/en/libero)

项目当前版本记录中，SmolVLA 使用 hf-libero 0.1.4 / MuJoCo 3.3.2，PulseVLA 使用 hf-libero 0.1.3 / MuJoCo 3.3.2，VLA-Adapter 使用原版 LIBERO / MuJoCo 2.3.7。以[主项目运行说明](../../README.md)、[源版本记录](../../configs/sources.json)及每次运行导出的实际依赖为准。这些配置用于复现各自基线，不能直接据原始 SR 或 FR 给三模型排鲁棒性名次。

初期在每个模型及其固定环境内部做干净／攻击配对，报告 SR、失败增量、cASR 和预算曲线。若要进一步比较不同模型的鲁棒性差异，需要尽可能统一任务资产、对象、初始化、评价谓词、控制频率、暴露时间、终止条件和仿真版本，再复核各模型基线。无法统一的部分分表报告并列为限制；不同训练数据组织和每套件权重差异也记录，不能将所有差异归因于架构。

策略调用数、执行控制步、预测块长度和实际执行长度分别记账。一次对外策略预测请求记为一次查询，内部采样步骤只计入计算成本，读取已有动作队列不新增查询；批量为 1 时按这一口径比较，批量扩展另记请求数与观察数。相同查询数可能覆盖不同控制时长，因此主表同时展示总调用预算、rollout 数、GPU／墙钟时间及暴露长度；需要时增加匹配执行长度的对照。动作偏移仅在同一模型、同一状态下按冻结尺度比较，不把不同动作表征的原始 L2 放在一起排名。

同一仿真器中的背景或布局变化支持跨条件结论。额外仿真器、机器人平台或真实场景属于跨环境扩展，暂不纳入最低完成要求。实验在项目的 WSL2 / Linux GPU 环境中运行，计划与结果索引保存在主项目目录。

### 留出验证要求

| 维度 | 验证设计 | 能支持的结论 |
| --- | --- | --- |
| 跨任务 | 发现阶段的任务与确认阶段任务分开，覆盖对象、属性与关系相关任务 | 对所覆盖任务类型的适用范围 |
| 跨模型 | 相同构造规则在不同架构上评估，分别报告自然能力 | 对已测模型配置的复现性 |
| 跨初始化和布局 | 不复用发现阶段初始化；布局变化保持目标可执行性 | 对初始状态与布局变化的稳定性 |
| 跨表达模板 | 冻结事实内容，使用未参与筛选的表达方式 | 是否依赖特定词句或修辞 |
| 跨视觉条件 | 在目标仍可见、动作仍可行的范围内测试光照、背景和区域位置 | 是否依赖特定视觉载体 |
| 跨执行阶段 | 同样的干扰规则在不同状态阶段进入、撤除 | 时序依赖与恢复边界 |

确认阶段前冻结模板、强度范围、事件判据和主要统计比较。新模型上重新搜索的结果称为适应后攻击；冻结候选直接应用的结果才称为迁移。保存效应消失和符号改变的条件，不只展示成功案例。

推进条件是：至少一个有明确行为意义的现象在独立任务或初始化集合中复现，且已排除明显的目标变化、自然失败和干扰预算差异。跨架构若不复现，则收窄研究对象；不强制把局部结果包装成普遍规律。

## 可复现实验资产

每个任务样本记录 `task_id、scene_id、initial_state_id、goal_object_id、goal_predicate、instruction_original、instruction_variant、context_role、conflict_type、feasibility、visual_transform、strength、exposure_schedule`。每次运行再记录模型与代码版本、预处理、随机种子、输入配置、控制频率、动作块长度、完成和风险事件、模型调用数及日志位置。

主导诊断另记 `diagnostic_role、query_block、target_visual、target_text、cue_validity、reference_trajectory、outcome_A、outcome_B、event_times、indeterminate_reason`。载体及模板尝试全部登记为探索，不以没有进入最终矩阵为由遗漏成本或已见数据。

数据划分按任务、场景、对象或表达模板组织；先导、验证和确认集合使用独立索引。完整状态保存包括模拟器状态、策略缓存与随机状态，防止“同初始状态”仍存在隐性差异。

保存逐任务结果，主表采用任务宏平均，并提供总体 episode 汇总。保存成功、自然失败、攻击失败和恢复视频；优先用仿真对象 ID、接触和位置事件标注，再对歧义案例人工复核。LLM 裁判可以辅助审查自然语言，但不能替代动作真值。

建议最终保留五组核心图表：条件化行为图谱、四组概率与 Γ 的强度曲线、干扰进入撤除后的行为与恢复曲线、动作代理与实际失败的对应关系、跨模型留出验证与查询预算曲线。探针和干预结果只在确实开展可选白盒分析时补充。
## 主模型与验证候选的报告结构

| 结果表 | VLA-Adapter（主／源模型） | SmolVLA（验证候选） | PulseVLA-LIBERO（验证候选） | 核心解释 |
| --- | --- | --- | --- | --- |
| 干净能力与成本 | 全任务及先导任务基线 | 相同任务索引，保留本模型成功子集 | 相同任务索引，保留本模型成功子集 | 先说明每个模型能够完成什么、自然失败与成本是多少 |
| 方法适用性 | 留出集合上的冻结算法结果 | 同算法和预算下在本模型搜索 | 同算法和预算下在本模型搜索 | 方法在不同结构／同类架构上的适用性 |
| 冻结攻击迁移 | 独立初始化上的源模型评价 | 直接应用源模型候选，目标反馈不参与调参 | 直接应用源模型候选，目标反馈不参与调参 | 对已有候选的迁移能力及失效边界 |
| 组合与时序 | 四组 Γ 与恢复 | 同规则配对验证 | 同规则配对验证 | 交互现象是否复现，不由搜索收益替代 |

源模型固定标明 VLA-Adapter；两个候选列仅在相应模型通过自身前置核查并实际开展验证时填入结果，未开展或能力不通过应如实标注。由目标模型评价结果挑选最有效候选后再次报告，会引入目标模型信息，须重新归类并使用独立测试集合。跨模型共同成功子集、基于基线筛选的任务池与全任务分别列示；SmolVLA 与 PulseVLA 仍不能视为两个独立架构路线。
